# 🌸 Anushka's Personal Introduction Page

## 📖 About the Project

Welcome to my Personal Introduction Page! This is a simple and colourful personal portfolio website created using **HTML5 and CSS3**. It introduces me, my education, skills, goals, and interests through a beautiful, colourful, and responsive design.

## ✨ Features

- 💗 **About Me:** A short personal introduction.
- 🎓 **Education:** Information about my academic background.
- 💻 **Skills:** Technologies I am learning, including Java, HTML, CSS, and Web Development.
- 🎯 **Goals:** My future career goals.
- 🌈 **Interests:** My interests and hobbies.
- 🎨 **Colourful Design:** Gradient backgrounds, colourful cards, rounded corners, and hover animations.
- 📱 **Responsive Layout:** Designed to adapt to smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📂 Project Structure

```text
webdev-day02/

```

## 🚀 How to Run the Project

1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your browser, or right-click it in VS Code and select **Open with Live Server**.
5. Enjoy exploring my personal introduction page!
